JackNBox

September 2024 - November 2024 | 100hrs

Commentary

This project was completed for an assignment called 'Unfriendly Interfaces' in my Media Programming course (NMDS5444). As JavaScript, CSS, and HTML were new to me, this project emerged out of experiments practicing the language. My experiments led me to the curiousity of working with iframe and window objects. I learned that programs can be written which can open up new browser windows. I found this effect to resonate with my childhood experiences using the internet and feeling scared by popups and unusual websites appearing. Additionally, my older sister would scare me with videos or computer games containing jump scares like the scary maze game. So, I decided to imagine an unfriendly interface as one which induces fear through an unsuspecting and unnatural behavior. The metaphor of the Jack in the Box toy served as a conceptual reference.

From a technical level, I utilized a JS library to create a page turning effect when clicking the right arrow. Additionally, I utilized Meta's Segment Anything SAM2 model to automatically cut-out successive images of the clown seen dancing ontop of the box as the pages are turned. I think the glitch aesthetic effect is spooky and phantom like as comes from errors in the ML model. I wrote an automated script in Python to chop up an audio file into successive .5 sec clips which trigger at each page turn. This gives the user control to choose to proceed in winding up the Jack in the Box. When the sound reaches its critical point (pop goes the weasel), I have the image switch to one of the open box, and have a slight delay before the animation stops and the windows begin to open. I used the setInterval function to time the opening of successive windows in random locations every second. There is a creepy robotic error message playing after each window opens which quickly turns into an eerie cacophony. Thus, unfriendly again because the user must quickly figure out how to make the noise stop and manually close out of all the windows.

This project draws attention to analog and discrete media. A physical Jack in the Box is an analog device through mechanical rotation to generate sound. This project is fully discrete as button clicks are used to trigger discrete samples of audio. However, the movement of the animation is done frame by frame in a similar way to how analog tape reels through a projector. Additionally, this project connects with other references to cursed or haunted media. For example, movies like The Ring, Sinister, and the Evil Dead portray analog technologies as unleashing a curse upon playback. I think this theme is suggestive of our tendencies to associate the paranormal and spiritual with new electronic media forms. Yet, there is a curiousity to seek out those and reveal those scary / unnatural behaviors in machines.
