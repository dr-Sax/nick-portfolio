Web Cutups

October 2024 - November 2024 | 100hrs

Commentary

This project was created as part of a media programming class at The New School taught by Fabiola Hanna. Inspired by an interactive collage art installation at the Cleveland Museum of Art, I recreated a web extension version. Whereas the museum version allows users to collage from existing sculptures, paintings and other artworks in the museum's collection, this remixed version focuses on the web as a source of college material and in particular dynamic page content like youtube videos. The libraries used were three.js and p5.js as well as conversation with Claude.AI as a co-author. I plan to build off of this project in future course work with respect to audio and video timing. As for now, all videos play at equal volume and loop according to when the videos are pasted into the three.js assembler window. I hope to incorporate the Youtube video player api in future versions to customize control of video timing. Secondly, I plan to utilize this framework in designing Web Mixed Reality Experiences by linking object tracking in the camera's environment to layered contents.
